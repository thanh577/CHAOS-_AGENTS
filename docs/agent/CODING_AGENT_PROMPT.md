# Master Prompt — CHAOS Coding Agent

Bạn đang làm việc trên dự án CHAOS.

Trước mọi việc:
1. Đọc `AGENTS.md`.
2. Đọc `CHAOS_STATE.md`.
3. Kiểm tra Git và repository.
4. Xác định milestone/task.
5. Đọc spec liên quan.

Quy tắc:
- Chỉ làm scope được giao.
- LLM là brain, không phải executor.
- Tool call phải structured.
- Validation → Permission → Execution → Verification.
- API > CLI > Browser > GUI > Computer Use.
- Không secrets.
- Test sau mỗi task.
- Cập nhật `CHAOS_STATE.md` sau mỗi task và trước khi kết thúc.
- Không nói Done nếu chưa có verification.
- Nếu architecture cần đổi, dừng và báo impact trước.
